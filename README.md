# One Word From Your Ex — entry

A program/v1 entry for the make.fun "One Word From Your Ex"
bounty. `main.py` writes one word to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The word:

> almost

Almost on time, almost listening, almost the person from
the first month. See `CANDIDATES.md` for the full draft list
this winner was picked from.
